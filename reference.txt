    curl -i http://192.168.56.2:8080/

  Click the Clear Kali Requests button on the dashboard to verify that it wipes the Kali logs and resets the counter to     
  0.                                                                                                                        
                                                                                                                            
  #### 3. Test Phase 2 (The Defense)                                                                                        
                                                                                                                            
  In a Windows PowerShell (Run as Administrator) window, enable the defense block rule:                                     
                                                                                                                            
    Set-NetFirewallRule -DisplayName "CyberLab - Block Kali" -Enabled True                                                  
                                                                                                                            
  Then send another request from Kali:                                                                                      
                                                                                                                            
    curl -m 3 -i http://192.168.56.2:8080/                                                                                  
                                                                                                                            
  The request will time out because Windows Firewall drops the packet before it reaches port 8080.
